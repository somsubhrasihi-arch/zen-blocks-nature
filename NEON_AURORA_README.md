# Neon Aurora update

Includes glowing gradient blocks, animated aurora sky, twinkling stars, line-clear sparkles, five rotating level palettes, and an effects toggle. Original gameplay and GitHub Actions APK build are retained.

To install from your phone: open Actions > Build Zen Blocks Android APK, select the latest successful run (or Run workflow), then download the ZenBlocks-Nature-Android-APK artifact and extract app-debug.apk. The existing workflow and artifact name are preserved.

Note: The provided artwork was a visual concept. This update implements its visual direction using Flutter CustomPainter, without bundled background image assets.
